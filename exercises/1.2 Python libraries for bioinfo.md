## 1. NumPy

**Description**
NumPy is the foundation of numerical computing in Python.
It provides fast, memory-efficient arrays (`ndarray`) and vectorized operations.
Compared to Python lists, NumPy arrays enable broadcasting, slicing, and mathematical operations at scale.
It is widely used in data science, machine learning, and scientific computing.
Understanding NumPy is essential before moving to higher-level libraries like pandas or scikit-learn.

📘 Docs: [https://numpy.org/doc/stable/](https://numpy.org/doc/stable/)

**Demo**

```python id="npdemo1"
import numpy as np

arr = np.array([1, 2, 3])
print(arr * 2)  # [2 4 6]
```

## 9. sqlite3

**Description**
`sqlite3` is a lightweight relational database engine embedded in Python.
It allows persistent data storage using SQL without needing a separate server.
You can create tables, insert/query data, and enforce constraints.
Transactions ensure data integrity, and parameterized queries prevent SQL injection.
SQLite is commonly used in local applications, testing, and prototyping.

📘 Docs: [https://docs.python.org/3/library/sqlite3.html](https://docs.python.org/3/library/sqlite3.html)
📘 Extra: [https://en.wikipedia.org/wiki/SQLite](https://en.wikipedia.org/wiki/SQLite)

**Demo**

```python id="sqldemo2"
import sqlite3

conn = sqlite3.connect(":memory:")
cur = conn.cursor()

cur.execute("CREATE TABLE users (id INTEGER, name TEXT)")
cur.executemany("INSERT INTO users VALUES (?, ?)", [(1, "Alice"), (2, "Bob")])

for row in cur.execute("SELECT * FROM users WHERE id > ?", (0,)):
    print(row)
```

## 10. multiprocessing

**Description**
The `multiprocessing` module enables parallel execution using separate processes.
Unlike threading, it avoids the Global Interpreter Lock (GIL), making it ideal for CPU-bound tasks.
It provides tools like `Pool`, `Process`, and inter-process communication (IPC).
However, processes do not share memory easily, so data must be serialized (pickled).
Careful design is required to avoid overhead outweighing performance gains.

📘 Docs: [https://docs.python.org/3/library/multiprocessing.html](https://docs.python.org/3/library/multiprocessing.html)
📘 Extra: [https://en.wikipedia.org/wiki/Multiprocessing](https://en.wikipedia.org/wiki/Multiprocessing)

**Demo**

```python id="mpdemo2"
from multiprocessing import Pool
import time

def work(x):
    time.sleep(1)
    return x * x

if __name__ == "__main__":
    with Pool(4) as p:
        print(p.map(work, [1, 2, 3, 4]))
```

**Exercise — Parallel vs Sequential Benchmark**

* Run it:

  * sequentially
  * with `multiprocessing.Pool`
* Measure execution time for both
* Print and compare results

## 11. PyTorch

**Description**
PyTorch is a deep learning framework centered around tensor computation and automatic differentiation.
It allows dynamic computation graphs, making it intuitive and flexible for research.
Tensors can run on CPUs or GPUs, enabling high-performance training.
The `autograd` system automatically computes gradients for optimization.
It is widely used in AI, computer vision, and natural language processing.

📘 Docs: [https://pytorch.org/docs/stable/](https://pytorch.org/docs/stable/)

📘 Extra: [https://en.wikipedia.org/wiki/PyTorch](https://en.wikipedia.org/wiki/PyTorch)

**Demo**

```python id="torchdemo2"
import torch

x = torch.tensor([2.0], requires_grad=True)
y = x ** 3 + 2 * x

y.backward()
print(x.grad)  # derivative: 3x^2 + 2
```

## 12. OpenMM

**Description**
OpenMM is a toolkit for molecular dynamics simulations used in computational chemistry and biophysics.
It enables simulation of molecular systems (e.g., proteins, solvents) using physics-based force fields.
One of its strengths is GPU acceleration for high-performance simulations.
It supports flexible system setup and integrates with scientific workflows.
Although powerful, it requires understanding of physical units and simulation concepts.

📘 Docs: [http://docs.openmm.org/](http://docs.openmm.org/)
📘 Extra: [https://en.wikipedia.org/wiki/Molecular_dynamics](https://en.wikipedia.org/wiki/Molecular_dynamics)

**Demo**

```python id="openmmdemo2"
from openmm import unit

distance = 1.0 * unit.nanometer
print(distance.value_in_unit(unit.angstrom))  # convert units
```
