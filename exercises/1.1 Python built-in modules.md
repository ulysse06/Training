## 1. try / raise

**Description**
Exception handling allows your program to deal with runtime errors gracefully instead of crashing.
`try` lets you test a block of code, while `except` handles errors.
`raise` allows you to trigger exceptions manually when invalid conditions occur.
This is essential for robust and user-friendly programs.

📘 Docs: [https://docs.python.org/3/tutorial/errors.html](https://docs.python.org/3/tutorial/errors.html)

```python

```

* Return `a / b`
* If `b == 0`, raise a `ValueError` with message `"Cannot divide by zero"`
* Handle the exception and return `"Error"` instead

## 2. assert

**Description**
`assert` is used for debugging and testing assumptions in code.
It checks if a condition is `True`, otherwise raises an `AssertionError`.
Useful for catching bugs early during development.
Assertions can be disabled in optimized execution.

## 3. lambda expressions

**Description**
Lambda functions are small anonymous functions defined in one line.
They are often used for short operations passed to functions like `map`, `filter`, or `sorted`.
They improve conciseness but should remain simple for readability.

## 4. Loop Control Statements

**Description**
Loop control statements modify how loops behave.
`break` exits the loop early, `continue` skips to the next iteration, and `pass` does nothing.
These are useful for controlling flow in complex loops.

📘 Docs: [https://docs.python.org/3/tutorial/controlflow.html#break-and-continue-statements](https://docs.python.org/3/tutorial/controlflow.html#break-and-continue-statements)
